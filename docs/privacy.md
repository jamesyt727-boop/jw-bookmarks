# JW Bookmarks 隐私政策

最后更新：2026-10-16

## 一句话

所有数据都留在你的本机。只有当**你自己配置了模型服务**时，「网页标题 + 网址」才会发送到**你自己填写的** API 地址。

## 一、本扩展读取什么

- `bookmarks`（书签）：读取你的收藏夹结构，用于生成候选文件夹，并在需要时把书签移动到目标文件夹。这是核心功能，**读取内容不做任何上传**。
- `activeTab`（当前标签页）：仅在你主动点击扩展按钮时，读取当前页面的标题和网址。

## 二、本扩展存什么（全部在本机）

| 数据 | 存放位置 | 是否随账号同步 |
| --- | --- | --- |
| Jev / DeepSeek 的 API Key | `chrome.storage.local` | 否 |
| 分类阈值、等待时长等配置 | `chrome.storage.local` | 否 |
| 本地规则、排除文件夹列表 | `chrome.storage.local` | 否 |
| 归档文件夹 id | `chrome.storage.local` | 否 |
| 选择弹窗的临时数据 | `chrome.storage.session`（关闭浏览器即清除） | 否 |

以上数据**不会**上传到任何服务器，也**不会**随 Google 账号同步到其它设备。

## 三、联网行为

- **只有「本地规则未命中」时才会联网。** 命中规则的书签完全不发请求。
- 发送的内容**仅为「网页标题 + 网址」**：不抓取网页正文，不发送你的其它书签。
- 请求只发往**用户自己在设置里填写的**两个地址（默认 `https://api.typesafe.ai` 与 `https://api.deepseek.com`）。本扩展没有开发者的服务器。

## 四、本扩展不做什么

- 无统计埋点、无遥测、无第三方服务器中转
- 不读取浏览历史、不读取 cookies、不注入或篡改网页内容
- 不上传书签列表
