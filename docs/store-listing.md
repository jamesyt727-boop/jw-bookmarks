# Chrome Web Store 上架文案

## 名称
JW Bookmarks

## 简短说明（≤132 字符）
收藏网页时自动判断该放进哪个收藏夹。支持本地规则、AI 分析、批量整理与一键归档。需要自备模型 API Key。

## 详细说明
JW Bookmarks 帮你把收藏夹从「越攒越乱」变成「自动归位」。

**它怎么工作**
1. 先查你写的本地规则（不联网、零延迟）
2. 未命中时，由 AI 读懂网页内容并结合你现有的文件夹结构，给出候选
3. 很有把握就直接归位；拿不准就弹出 3 个候选（带概率）让你点一下

**主要功能**
- 收藏即归位：点地址栏星标后自动判断该放哪里
- 3 候选弹窗：给出概率值，一目了然
- 批量整理：扫描存量书签，高置信度自动归位，拿不准的列出来让你确认
- 一键归档：把旧文件夹整体收进归档文件夹，重新开始
- 批量新建文件夹、本地规则、排除文件夹、配置导出/导入

**使用前提**
本扩展需要你**自己准备模型服务的 API Key**（当前支持 TypeSafe Jev 与 DeepSeek，两者可分别配置）。不填 Key 时，仅本地规则可用。

**隐私**
所有数据都留在你的本机。只有本地规则未命中时才会联网，且仅发送「网页标题 + 网址」到你**自己配置的**地址。详见隐私政策。
