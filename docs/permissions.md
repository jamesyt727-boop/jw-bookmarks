# 隐私标签页 —— 各权限用途论证（直接复制填写）

## bookmarks（书签）
用于读取用户的收藏夹结构以生成候选文件夹，并在用户确认或高置信度时把书签移动到目标文件夹。这是本扩展的唯一核心功能；读取到的书签数据不上传、不共享。用户在「批量整理」中可对全部书签重新分类，同样只在本机完成。

## storage（存储）
用于在本机保存用户配置：API Key、分类阈值、本地规则、排除文件夹列表、归档记录。数据仅存于 chrome.storage.local，不随账号同步、不上传。另使用 chrome.storage.session 临时保存选择弹窗的数据，关闭浏览器即清除。

## contextMenus（右键菜单）
用于在网页右键菜单中提供「收藏到自动分类」入口。

## activeTab（当前标签页）
仅当用户主动点击扩展图标并使用「分析当前页 / 收藏并自动分类」功能时，读取当前标签页的标题与网址，用于分类判断。

## host_permissions: https://api.typesafe.ai/*
用户在设置中填写 TypeSafe Jev 的 API Key 后，扩展会调用该地址进行决策判断。请求仅包含待分类网页的标题与网址。用户可不配置此项，此时不会发起请求。

## host_permissions: https://api.deepseek.com/*
用户在设置中填写 DeepSeek 的 API Key 后，扩展会调用该地址进行网页内容分析与候选生成。请求仅包含待分类网页的标题、网址与用户现有文件夹名称。用户可不配置此项，此时不会发起请求。

## 远程代码
本扩展不加载、不执行任何远程代码。所有逻辑均包含在提交的安装包内。

## 数据收集声明建议勾选
- 本扩展**不收集**任何用户数据（不勾选任何「收集」项）
- 说明：书签与网页标题/网址仅在用户本机处理，或发送至用户自己配置的第三方 API；开发者不接收、不存储。
