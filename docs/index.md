# JW Bookmarks

**收藏即归位** —— 一个自动判断书签该放进哪个收藏夹的 Chrome 扩展（Manifest V3）。

![主界面](screenshots/01-主界面.png)

## 文档

- [**隐私政策**](privacy.html) — 上架 Chrome 应用商店所需
- [权限说明](permissions.html) — 各项权限的用途
- [应用商店描述](store-listing.html) — 商店文案与功能介绍

## 功能

| 特性 | 说明 |
| --- | --- |
| 🎯 收藏即归位 | 点一下星标，自动判断该放进哪个收藏夹 |
| 🤖 AI 双引擎 | DeepSeek 理解内容 → Jev 判断归类（概率经过校准）|
| 🗳️ 拿不准就问你 | 弹窗给 3 个候选 + 概率值，不硬猜 |
| 📦 批量整理 | 存量书签一键重排，跑在后台、关掉弹窗也不中断 |
| 🗄️ 一键归档 | 旧文件夹整体收进归档夹，重新开始 |
| 🔒 隐私优先 | 数据只在本机；仅规则未命中时发送「标题 + 网址」到**你自己配置的** API |
